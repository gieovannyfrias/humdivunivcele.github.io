Políticas de Seguridad

Directivas de infraestructura. Conoce las medidas adoptadas para la protección e integridad de la plataforma.

  • 1. Cifrado de Conexiones
  • 2. Integridad del Código
  • 3. Seguridad de Servidores
  • 4. Mitigación de Riesgos

1. Cifrado de Conexiones

Todo el tráfico de datos entrante y saliente en la plataforma viaja estrictamente bajo el protocolo seguro HTTPS con cifrado SSL/TLS de última generación. Esto garantiza que cualquier interacción del usuario, como el registro en el formulario de newsletter, permanezca completamente privada e inaccesible para intermediarios maliciosos.

2. Integridad del Código

Mantenemos una arquitectura de componentes web aislada y modular. Implementamos políticas estrictas de Seguridad de Contenido (CSP) que limitan el origen de ejecución de scripts y hojas de estilo externos. Esto anula por completo vectores de ataque comunes como la inyección de código malicioso de terceros (XSS) en la interfaz de la línea de tiempo.

3. Seguridad de Servidores

Los repositorios digitales y archivos de distribución (como hojas CSS, JavaScript e imágenes estáticas) se alojan en redes de distribución de contenido (CDN) distribuidas geográficamente. Estas infraestructuras cuentan con monitoreo perimetral ininterrumpido y firewalls dedicados a repeler ataques de denegación de servicio (DDoS) para garantizar una disponibilidad del 99.9%.

4. Desactivación y Control

Auditamos periódicamente la estructura lógica del proyecto, eliminando librerías deprecadas o scripts pesados en línea. En caso de detectarse anomalías o intentos de vulneración en los registros de acceso analíticos, nuestros sistemas aplican bloqueos de IP automatizados de forma inmediata para blindar el núcleo de la base de datos de los 101 elementos históricos.
